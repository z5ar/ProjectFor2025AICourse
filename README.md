# 纸牌游戏辅助机器人

---

## 1. 项目介绍

该项目预计采用神经网络配合其他算法，实现一个可以根据上家出牌、手牌情况等因素出牌进行辅助的人工智能。

鉴于本小组的成员都不会大作业要求中提出的“掼蛋”，本项目选择以另一流行纸牌游戏“UNO”为基础。

## 2. 游戏规则

本小组成员在于互联网上搜索之后，发现UNO纸牌规则众说纷纭。现将本项目实现的游戏规则整理如下：

### 2.0 牌面分类
UNO纸牌共108张牌，其中包含数字牌76张、功能牌24张和万能牌8张。

#### 2.0.1 数字牌

数字牌由红、黄、蓝、绿四种颜色组成。 每色包含数字1~9各两张、数字0仅1张，共19张，四色统共76张。

#### 2.0.2 功能牌

功能牌也由红、黄、蓝、绿四种颜色组成。每色包含“禁止”“反转”“+2”各2张，四色统共24张。

1. 禁止牌：打出此牌，下家禁止行动一回合。

2. 反转牌：打出此牌，此前的上家变为此后的下家，此前的下家变为此后的上家，也就是说，走牌方向将反转。

3. +2牌：打出此牌，下家摸两张牌，并禁止行动一回合。存在例外情况，详见2.2.2小节。

#### 2.0.3 万能牌
万能牌底色为黑色。包含“万用”“万用+4”各4张，统共8张。

1. 万用牌：打出此牌，可以在红、黄、蓝、绿四色中随意指定其一作为下家的出牌颜色。

2. 万用+4牌：打出此牌，下家摸四张牌，并禁止行动一回合，且可以在红、黄、蓝、绿四色中随意指定其一作为下下家的出牌颜色。本牌存在质疑规则，详见2.2.1小节。

### 2.1 基本规则

#### 2.1.1 开始游戏

游戏开始，每人摸牌7张。发完牌后，翻出牌堆最上方的一张牌，并以此作为起始牌，从庄家开始顺时针进行跟牌。
网络规则中存在庄家的选取问题，本项目为简化问题，简单地指定程序逻辑中的1号玩家作为庄家。

#### 2.1.2 跟牌规则

本小节中，将最近一轮打出的牌（首轮为起始牌）简称为参照牌。

参照牌非万能牌的情况下，符合下列三个条件中任意一个的牌，可以打出。
1. 与参照牌颜色相同。
2. 与参照牌内容（数字牌为数字、功能牌为功能）相同。
3. 万能牌。

若参照牌为万能牌，则需要按照打出该万能牌的玩家指定的颜色出牌，或者打出万能牌。

#### 2.1.3 无牌可出规则

若手牌中没有牌符合2.1.2中规定的规则，必须从牌堆中摸1张牌。

摸到的牌可以打出的，可选择打出或保留；摸到的牌不可以打出的，只能保留，本轮不可行动并让下家出牌。

#### 2.1.4 报单规则

任何一位玩家，在打出手中倒数第二张牌时，即出牌后手中只剩一张牌时，需喊出“UNO”。

鉴于形式的限制，本项目将不实现报单规则。

#### 2.1.5 结束规则

某一位玩家，打出手中最后一张牌，即为胜利。当有且仅有一位玩家未能打出手中所有的牌时，游戏结束。

#### 2.1.6 洗牌规则

若在结束前，即将无牌可摸，则将所有打出的手牌除最新一张外洗牌放回牌堆。

本项目中约定，当牌堆中最后一张牌被摸走之后才执行上述洗牌操作。

### 2.2 附加规则

#### 2.2.1 对于万用+4牌的质疑规则

本小节中，将打出万用+4牌的玩家称作A，将其下家称为B。

当且仅当手牌中只有万能牌符合2.1.2中跟牌规则时，万用+4牌可以被合法打出。

有且仅有B可以在摸4张牌之前对A使用万用+4牌的合法性提出质疑。提出质疑后，A需要展示手牌以确定其是否为合法使用。存在以下三种情况。
1. B不质疑，B直接抽4张牌，并禁止行动一回合。
2. B质疑且A的万用+4牌为合法使用，B抽6张牌，并禁止行动一回合。
3. B质疑且A的万用+4牌非合法使用，A抽4张牌，B可以按照2.1所述规则行动。

无论质疑与否、质疑成功与否，A对颜色的指定**仍然有效**。

为简化问题，本项目对于A使用万用+4牌的合法与否将通过程序判断，取消对手牌的展示环节。

#### 2.2.2 对于+2牌与万用+4牌的叠加规则

任意一位玩家打出+2牌时，其下家可以打出任意一种颜色的+2牌或万用+4牌，此时不受2.0.2所述规则影响。并且摸牌数将叠加计算。

任意一位玩家打出万用+4牌时，其下家**不可以**继续打出+2或万用+4牌，必须摸牌。

在这种情况下万用+4牌不受质疑。

#### 2.2.3 对于数字0的换牌规则

当任意玩家打出0牌时，所有玩家将全部手牌交给下家。

特别说明，当玩家打出的0牌为最后一张手牌时，其仍旧视作胜利。来自其上家的手牌直接交给其下家。
